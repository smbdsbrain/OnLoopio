# OnLoopio

**Альтернативная прошивка-плеер для Innioasis Y1 Type A.** OnLoopio объединяет музыку с Navidrome, локальные файлы и офлайн-загрузки в интерфейсе для колёсика и аппаратных кнопок. Выпуск содержит готовый образ BOOT + SYSTEM, установщик для Windows и контрольные суммы. APK приложен отдельно для разработчиков.

Поддерживается только проверенный профиль **Y1 Type A**. Type B требует отдельной проверки на устройстве.

Лайк можно поставить или снять через меню трека либо двойным нажатием нижней кнопки Play; музыка при этом не останавливается. В библиотеке доступен раздел «Любимые треки». Лайки Navidrome синхронизируются в обе стороны, а офлайн-прослушивания сохраняются после перезапуска и отправляются вместе с синхронизацией плейлистов. Лайки и статистика файлов из `Music` остаются на плеере. Подробнее — [модель синхронизации](sync-model.md).

## Быстрый старт

1. Скачайте ZIP прошивки Y1 Type A и `SHA256SUMS.txt` со страницы [Releases](https://github.com/smbdsbrain/OnLoopio/releases), проверьте контрольную сумму и распакуйте ZIP на Windows.
2. Выполните [инструкцию по установке и восстановлению](install.md). Установщик проверяет профиль устройства и сохраняет резервную копию до записи BOOT и SYSTEM.
3. После запуска подключите USB-накопитель Y1 к компьютеру и запустите `setup-usb.ps1`, указав букву диска. Введите Wi-Fi и Navidrome, безопасно извлеките накопитель и отсоедините плеер. Подробности — в [первоначальной настройке](setup.md).
4. Отметьте музыку для офлайн-доступа. Загрузки выполняются по вашему выбору.
